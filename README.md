# 远程桌面管理工具

一个单文件的 Windows 批处理脚本，用来**查看、开启、关闭远程桌面，并安全地修改远程桌面端口**。改端口时会同步处理防火墙规则，不用再手动去注册表和防火墙里翻。

## 它解决什么问题

手动改远程桌面端口要做的事不少：改两处注册表、放行新端口、处理旧的 3389 规则、重启服务，哪一步漏了都会连不上。这个脚本把整个流程做成菜单，并且**每一步都做验证**，防火墙规则没加成功就不会去动注册表，避免把自己锁在门外。

## 功能

- **启动即检测**：显示远程桌面是否开启、当前端口、端口是否正在监听。
- **识别真实局域网 IP**：自动排除 VMware、VirtualBox、Hyper-V 默认交换机、WSL、Docker、VPN 等虚拟网卡，直接给出可用的连接地址。
- **开启 / 关闭远程桌面**：一键开关，关闭时同时清理对应的防火墙规则。
- **修改端口**：
  - 检查端口格式和范围（1024-65535），并检查是否已被占用，会显示占用它的进程。
  - 同时添加 **TCP + UDP** 入站规则，并验证规则确实存在，`netsh` 失败时自动改用 PowerShell 重试。
  - 修改两处注册表。
  - 关闭旧端口规则：禁用所有指向 3389 和旧端口的入站放行规则，并删除本脚本之前创建的旧规则。
  - 重启远程桌面服务，并**等待新端口真正开始监听**才报告成功，而不是固定等几秒。
- **仅修复防火墙**：输入与当前相同的端口时，可只补防火墙规则、清理旧规则，不动注册表。
- **家庭版检测**：Windows 家庭版不支持作为远程桌面主机，会直接提示。

## 使用方法

1. 下载 `远程桌面管理工具.bat`（见下方"下载注意"）。
2. **右键 → 以管理员身份运行**（Win11 可能需要先点"显示更多选项"）。
3. 按菜单提示操作。

改端口时的典型流程：

```
选 1 → 输入新端口 → 确认 → 自动添加防火墙规则 → 修改注册表
     → 选择重启服务 → 等待约 10 秒 → 用「IP:新端口」重新连接
```

连接方式：`mstsc` 里输入 `192.168.x.x:新端口`，脚本结束时会直接给出完整地址。

### 下载注意（很重要）

脚本是 **GBK（ANSI）编码**，这样才能在简体中文 Windows 上正常显示中文。因此：

- **请使用 `git clone`、Releases 下载或 "Download ZIP"。**
- **不要**在 GitHub 网页上复制内容再粘贴到记事本保存，这样会变成 UTF-8，运行时出现乱码甚至跳转错误。
- GitHub 网页上直接预览该文件会显示乱码，这是正常的，不影响下载后的使用。
- 如果你要修改脚本，请用支持 GBK 的编辑器（如 VS Code 切换编码为 GBK、Notepad++），并保持 **CRLF** 换行。

## 工作原理

| 操作 | 涉及的位置 |
|---|---|
| 开启 / 关闭远程桌面 | `HKLM\System\CurrentControlSet\Control\Terminal Server` 下的 `fDenyTSConnections`（0 开启，1 关闭） |
| 开启时的服务设置 | `TermService` 设为自动启动并启动 |
| 修改端口 | `...\Terminal Server\WinStations\RDP-Tcp` 与 `...\Terminal Server\Wds\rdpwd\Tds\tcp` 下的 `PortNumber` |
| 防火墙放行 | 入站规则 `Custom Remote Connection Port (端口)` 和 `... (端口) UDP` |
| 关闭旧规则 | 禁用所有本地端口为 3389 或旧端口的、已启用的入站规则 |

**改端口的执行顺序**：先加防火墙规则并验证 → 再改注册表 → 再关旧规则 → 最后重启服务。任何一步失败都会停止并提示，不会留下改了一半的状态。

**局域网 IP 的识别规则**：只看已连接的网卡；必须有默认网关；排除 169.254.x.x 和名称中带虚拟网卡特征的接口；Hyper-V 外部交换机（主机地址挂在 `vEthernet (External)` 上）会被保留；有多个候选时有线优先。

## 常见问题

**改完端口后立刻连不上？**
服务重启需要几秒到十几秒才会开始监听新端口，等约 10 秒再连。主菜单显示"监听中"就说明已就绪。

**云服务器改完还是连不上？**
脚本只能改系统自带防火墙。云主机还需要在云厂商后台的**安全组**里放行新端口。

**提示 TCP 防火墙规则添加失败？**
检查 Windows Defender Firewall 服务是否在运行，或防火墙是否被 360、火绒等第三方软件、组策略接管。出现这种情况时脚本会在改注册表之前就停止。

**中文显示乱码？**
确认是简体中文系统，且文件没有被另存为 UTF-8。Windows 11 里如果开启了"Beta: 使用 Unicode UTF-8 提供全球语言支持"（区域设置 → 管理语言设置），会导致 GBK 脚本乱码，关闭后重启即可。

**杀毒软件报警？**
脚本会修改注册表和防火墙，部分安全软件会拦截或提示，属于正常现象。脚本是纯文本，源码完全可读，可自行审阅后再运行。

**想恢复默认的 3389？**
运行脚本，选 1，输入 `3389` 即可。

**当前就在用远程桌面操作这台机器，安全吗？**
改端口并重启服务会断开当前连接，请等待约 10 秒后用新端口重连。如果是在远程操作，建议先确认云安全组 / 路由器已放行新端口，并且手边有能登录本机或控制台的备用方式。

## 安全建议

修改端口只能减少被自动化扫描撞到的概率，**不等于安全加固**。如果远程桌面需要暴露在公网，更重要的是：使用强密码、保持网络级别身份验证（NLA）开启、限制来源 IP，或者放在 VPN 后面。
